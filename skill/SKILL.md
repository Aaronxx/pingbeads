# 拼豆图纸生成器

## 业务描述

将用户提供的图片转换为 MARD 品牌拼豆色彩马赛克图纸。支持 291 种 MARD 标准色号的精确映射，帮助用户购买对应颜色的拼豆进行手工制作。

## 适用场景

当用户有以下需求时调用此 SKILL：

1. **生成拼豆图纸**：用户提供图片，希望转换为拼豆马赛克图案
2. **查询颜色统计**：用户想知道图纸需要哪些颜色、各多少个
3. **获取采购清单**：用户需要购买拼豆的材料清单（CSV 格式）
4. **调整图纸参数**：用户想改变格子大小、颜色合并程度等

## 核心概念

### MARD 色号
MARD 是德国拼豆品牌，有 291 种标准颜色。色号格式为字母+数字，如 A01、B12、C23。

### 处理模式
- **卡通模式**（默认）：普通网格化处理，适合卡通、插画类图片
- **马赛克模式**：智能色块合并，适合照片类图片

### 关键参数
- **网格大小（gridSize）**：控制格子数量，5-50，数值越小格子越多越精细
  - 5 = 超级多（非常精细）
  - 8 = 多
  - 10 = 中等（默认）
  - 15 = 少一点
  - 20 = 再少一点
  - 30 = 比较少
  - 50 = 超级少（非常粗糙）
- **合并阈值（mergeThreshold）**：0-291，数值越大颜色合并越多，色号种类越少
  - 0 = 不合并（保留所有细节）
  - 50 = 中等合并（默认）
  - 291 = 最大合并（颜色种类最少）
- **去边缘（removeEdge）**：是否去除图片边缘的底色，默认 true
- **特殊色（useSpecialColors）**：是否使用 P/Q/R/T/ZG 系列特殊色，这些颜色较难购买，默认 false
- **镜像（mirrorImage）**：是否镜像翻转图纸，用于熨烫前查看背面效果，默认 false
- **鲜艳度（vibrantScale）**：-10 到 10，调整颜色鲜艳程度
  - -10 = 最柔和（复古风格）
  - 0 = 原色（默认）
  - 10 = 最鲜艳（高饱和度）

## 输出说明

### 图纸数据
返回马赛克网格信息，包括：
- 行列数（cols × rows）
- 每个格子的 MARD 色号
- 颜色统计（各色号使用数量）

### 采购清单
CSV 格式文本，包含：
- 色号
- 颜色名称
- 所需数量

## 注意事项

1. 图片会先上传到临时路径再处理
2. 处理时间取决于图片大小和参数，通常 2-5 秒
3. 导出的 CSV 使用 UTF-8 编码，可直接导入 Excel
4. 当前版本暂不支持自定义色卡，固定使用 MARD 291 色
5. 图片尺寸限制为 4086×4086 像素以内，超过会自动缩放
6. 图纸数据在会话期间有效（1小时内），过期需重新生成
7. 马赛克模式适合照片类图片，卡通模式适合插画、卡通图
8. 导出 PNG 图片时，如果图纸尺寸过大（超过 4096px），会提示导出限制

## 错误处理

所有接口返回统一的错误格式：

```json
{
  "success": false,
  "errorCode": 1001,
  "message": "用户友好的错误提示",
  "details": { /* 可选的错误详情 */ }
}
```

### 错误码分类

| 错误码范围 | 分类 | 说明 |
|-----------|------|------|
| 1001-1999 | 图片相关 | 图片不存在、过大、加载失败等 |
| 2001-2999 | 参数相关 | 参数无效、缺少必要参数等 |
| 3001-3999 | Canvas 相关 | Canvas 不可用、初始化失败等 |
| 4001-4999 | 算法相关 | 算法执行错误、返回空数据等 |
| 5001-5999 | 存储相关 | 存储错误、数据不存在等 |
| 6001-6999 | 环境相关 | wx API 不可用等 |

### 常见错误码

| 错误码 | 含义 | 解决建议 |
|--------|------|----------|
| 1001 | 图片不存在 | 检查图片路径或重新选择 |
| 1002 | 图片尺寸过大 | 已自动缩放至 4086×4086 |
| 1003 | 图片加载失败 | 尝试重新选择或使用其他图片 |
| 2002 | 缺少必要参数 | 检查接口调用参数 |
| 3001 | Canvas 不可用 | 升级微信版本 |
| 3004 | 图纸尺寸过大 | 减小 gridSize 参数 |
| 5002 | 图纸不存在 | 重新生成图纸 |
| 5003 | 图纸数据已过期 | 重新生成图纸（超过1小时） |

## 最佳实践

### 参数选择建议

1. **图片类型**：
   - 照片类 → 使用 `mosaic` 模式
   - 插画/卡通 → 使用 `cartoon` 模式

2. **图片大小**：
   - 大图（>100万像素）→ gridSize: 20-30, mergeThreshold: 80-100
   - 中图（30-100万像素）→ gridSize: 10-15, mergeThreshold: 50-70
   - 小图（<30万像素）→ gridSize: 5-10, mergeThreshold: 20-50

3. **颜色种类控制**：
   - 想要颜色种类少 → 增大 `mergeThreshold`
   - 想要保留细节 → 减小 `mergeThreshold`

### 性能优化

1. **图片缓存**：系统会自动缓存已处理的图片像素数据，相同图片重复调用会更快
2. **进度反馈**：长耗时操作建议传入 `onProgress` 回调，让用户知道处理进度
3. **参数建议**：不确定参数时，先调用 `suggestProcessingParams` 获取推荐值

### 错误处理

1. **重试机制**：对于临时性错误（如网络问题），可以自动重试 1-2 次
2. **降级方案**：如果 Canvas 不可用，提示用户使用小程序原生功能
3. **用户提示**：使用返回的 `message` 字段直接展示给用户，无需额外翻译
