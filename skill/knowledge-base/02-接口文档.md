# 拼豆图纸生成器 - 接口详细文档

## 接口总览

| 接口名称 | 功能 | 必需参数 | 返回数据 |
|---------|------|---------|---------|
| generateBeadMosaic | 生成拼豆马赛克图纸 | imageUrl | mosaicId, cols, rows, colorStats |
| getColorStats | 获取颜色统计 | mosaicId | colorStats, totalCells, colorCount |
| getPurchaseList | 导出采购清单 | mosaicId | content, format, totalColors |
| exportMosaicPNG | 导出图纸图片 | mosaicId | tempFilePath, width, height |
| suggestProcessingParams | 智能参数推荐 | imageUrl | suggestedParams, explanation |
| getMosaicDetail | 获取图纸详情 | mosaicId | 完整图纸信息 |
| deleteMosaic | 删除图纸 | mosaicId | 删除确认 |

---

## 1. generateBeadMosaic - 生成拼豆马赛克图纸

### 功能说明
将图片转换为 MARD 品牌拼豆色彩马赛克图纸，返回图纸数据和颜色统计。

### 请求参数

| 参数名 | 类型 | 必需 | 默认值 | 范围 | 说明 |
|--------|------|------|--------|------|------|
| imageUrl | string | 是 | - | - | 图片临时路径 |
| processMode | string | 否 | cartoon | cartoon/mosaic | 处理模式 |
| gridSize | integer | 否 | 10 | 5-50 | 网格大小（像素） |
| mergeThreshold | integer | 否 | 50 | 0-291 | 颜色合并阈值 |
| removeEdge | boolean | 否 | true | - | 是否去除边缘 |
| useSpecialColors | boolean | 否 | false | - | 是否使用特殊色 |
| mirrorImage | boolean | 否 | false | - | 是否镜像 |
| vibrantScale | integer | 否 | 0 | -10~10 | 鲜艳度 |
| onProgress | function | 否 | null | - | 进度回调 |

### 返回数据

```json
{
  "success": true,
  "data": {
    "mosaicId": "mosaic_1234567890_abc123",
    "cols": 50,
    "rows": 40,
    "totalCells": 2000,
    "colorCount": 25,
    "processMode": "cartoon",
    "gridSize": 10,
    "mergeThreshold": 50,
    "colorStats": [
      {
        "code": "A01",
        "hex": "#FAF4C8",
        "count": 150
      }
    ]
  }
}
```

### 使用示例

```javascript
// 基本使用
const result = await generateBeadMosaic({
  imageUrl: '/tmp/image.jpg'
});

// 带进度反馈
const result = await generateBeadMosaic({
  imageUrl: '/tmp/image.jpg',
  gridSize: 15,
  mergeThreshold: 80,
  onProgress: ({ stage, percent, message }) => {
    console.log(`${percent}% - ${message}`);
  }
});
```

## 2. getColorStats - 获取颜色统计

### 功能说明
获取已生成图纸的颜色统计信息，支持排序和百分比计算。

### 请求参数

| 参数名 | 类型 | 必需 | 默认值 | 说明 |
|--------|------|------|--------|------|
| mosaicId | string | 是 | - | 图纸唯一标识 |
| sortBy | string | 否 | count | 排序方式：count/code |

### 返回数据

```json
{
  "success": true,
  "data": {
    "mosaicId": "mosaic_1234567890_abc123",
    "totalCells": 2000,
    "colorCount": 25,
    "colorStats": [
      {
        "code": "A01",
        "hex": "#FAF4C8",
        "count": 150,
        "percentage": "7.50"
      }
    ]
  }
}
```

### 使用示例

```javascript
// 按数量排序（默认）
const result = await getColorStats({
  mosaicId: 'mosaic_1234567890_abc123',
  sortBy: 'count'
});

// 按色号排序
const result = await getColorStats({
  mosaicId: 'mosaic_1234567890_abc123',
  sortBy: 'code'
});
```

## 3. getPurchaseList - 导出采购清单

### 功能说明
生成拼豆采购清单，支持 CSV 和纯文本两种格式。

### 请求参数

| 参数名 | 类型 | 必需 | 默认值 | 说明 |
|--------|------|------|--------|------|
| mosaicId | string | 是 | - | 图纸唯一标识 |
| format | string | 否 | csv | 输出格式：csv/text |

### 返回数据

```json
{
  "success": true,
  "data": {
    "content": "﻿色号,颜色,数量\nA01,#FAF4C8,150\n...",
    "format": "csv",
    "totalColors": 25,
    "totalQuantity": 2000
  }
}
```

### 使用示例

```javascript
// 导出 CSV 格式
const result = await getPurchaseList({
  mosaicId: 'mosaic_1234567890_abc123',
  format: 'csv'
});

// 导出纯文本格式
const result = await getPurchaseList({
  mosaicId: 'mosaic_1234567890_abc123',
  format: 'text'
});
```

## 4. exportMosaicPNG - 导出图纸图片

### 功能说明
将图纸导出为 PNG 图片，可选择是否显示色号和统计信息。

### 请求参数

| 参数名 | 类型 | 必需 | 默认值 | 说明 |
|--------|------|------|--------|------|
| mosaicId | string | 是 | - | 图纸唯一标识 |
| includeStats | boolean | 否 | true | 是否包含统计信息 |
| showCode | boolean | 否 | true | 是否显示色号 |

### 返回数据

```json
{
  "success": true,
  "data": {
    "tempFilePath": "wxfile://tmp_xxx.png",
    "width": 1000,
    "height": 800
  }
}
```

### 使用示例

```javascript
// 导出完整图纸（带色号和统计）
const result = await exportMosaicPNG({
  mosaicId: 'mosaic_1234567890_abc123',
  includeStats: true,
  showCode: true
});

// 仅导出图纸（不带统计）
const result = await exportMosaicPNG({
  mosaicId: 'mosaic_1234567890_abc123',
  includeStats: false
});
```

### 限制说明
- 画布尺寸限制：4096×4096 像素
- 如果图纸过大，会返回错误提示
- 建议先调整 gridSize 参数减小图纸尺寸

## 5. suggestProcessingParams - 智能参数推荐

### 功能说明
根据图片特征自动推荐合适的处理参数，包括 gridSize、mergeThreshold、processMode 等。

### 请求参数

| 参数名 | 类型 | 必需 | 说明 |
|--------|------|------|------|
| imageUrl | string | 是 | 图片临时路径 |

### 返回数据

```json
{
  "success": true,
  "data": {
    "imageInfo": {
      "width": 2000,
      "height": 1500,
      "orientation": "landscape"
    },
    "suggestedParams": {
      "gridSize": 20,
      "mergeThreshold": 80,
      "processMode": "mosaic",
      "removeEdge": true,
      "useSpecialColors": false,
      "mirrorImage": false,
      "vibrantScale": 0
    },
    "explanation": "图片尺寸 2000×1500 (3M像素)，大图，建议使用较粗的网格(20px)和较大的合并阈值(80)。由于图片较大，建议使用马赛克模式以获得更好的效果"
  }
}
```

### 参数推荐规则

| 图片像素数量 | 推荐 gridSize | 推荐 mergeThreshold | 推荐 processMode |
|------------|--------------|-------------------|-----------------|
| >400万 | 25 | 100 | mosaic |
| 100-400万 | 20 | 80 | mosaic |
| 30-100万 | 12 | 50 | cartoon |
| 10-30万 | 8 | 30 | cartoon |
| <10万 | 6 | 20 | cartoon |

### 使用示例

```javascript
// 获取参数建议
const result = await suggestProcessingParams({
  imageUrl: '/tmp/image.jpg'
});

// 使用推荐的参数生成图纸
const mosaic = await generateBeadMosaic({
  imageUrl: '/tmp/image.jpg',
  ...result.data.suggestedParams
});
```

## 6. getMosaicDetail - 获取图纸详情

### 功能说明
获取图纸的完整详细信息，包括基本属性、颜色统计，以及可选的网格数据。

### 请求参数

| 参数名 | 类型 | 必需 | 默认值 | 说明 |
|--------|------|------|--------|------|
| mosaicId | string | 是 | - | 图纸唯一标识 |
| includeGridData | boolean | 否 | false | 是否包含网格数据 |

### 返回数据

```json
{
  "success": true,
  "data": {
    "mosaicId": "mosaic_1234567890_abc123",
    "cols": 50,
    "rows": 40,
    "totalCells": 2000,
    "colorCount": 25,
    "gridSize": 10,
    "mergeThreshold": 50,
    "processMode": "cartoon",
    "removeEdge": true,
    "imageUrl": "/tmp/image.jpg",
    "createdAt": 1234567890000,
    "age": 3600000,
    "colorStats": [...],
    "gridData": [...] // 仅当 includeGridData=true 时返回
  }
}
```

### 注意事项
- `includeGridData=true` 时返回的数据量较大，谨慎使用
- `age` 字段表示图纸年龄（毫秒），超过 3600000（1小时）会自动清理
- 网格数据包含每个格子的色号和颜色值

## 7. deleteMosaic - 删除图纸

### 功能说明
删除图纸数据，释放内存。

### 请求参数

| 参数名 | 类型 | 必需 | 说明 |
|--------|------|------|------|
| mosaicId | string | 是 | 图纸唯一标识 |

### 返回数据

```json
{
  "success": true,
  "data": {
    "mosaicId": "mosaic_1234567890_abc123",
    "message": "图纸已成功删除"
  }
}
```

### 使用场景
- 用户主动要求删除图纸
- 清理过期数据
- 释放内存空间

## 通用返回格式

### 成功响应
```json
{
  "success": true,
  "data": { /* 响应数据 */ }
}
```

### 失败响应
```json
{
  "success": false,
  "errorCode": 1001,
  "message": "用户友好的错误提示",
  "details": { /* 可选的错误详情 */ }
```

### 错误码分类
- 1xxx：图片相关错误
- 2xxx：参数相关错误
- 3xxx：Canvas 相关错误
- 4xxx：算法相关错误
- 5xxx：存储相关错误
- 6xxx：环境相关错误

详细错误码请参考 [错误处理指南](./错误处理.md)
