# 拼豆图纸生成器 - 最佳实践

## 参数选择指南

### 根据图片类型选择处理模式

| 图片类型 | 推荐模式 | 理由 |
|---------|---------|------|
| 照片（风景、人物） | mosaic（马赛克） | 智能色块合并，效果更好 |
| 插画、卡通图 | cartoon（卡通） | 网格化处理，保留细节 |
| 像素画、图标 | cartoon（卡通） | 保持原有像素风格 |
| 抽象艺术 | mosaic（马赛克） | 色块合并可产生独特效果 |

### 根据图片尺寸推荐参数

#### 超大图（>400万像素，如 3000×2000）
```javascript
{
  processMode: 'mosaic',
  gridSize: 25,        // 粗网格，减少处理时间
  mergeThreshold: 100, // 大合并，减少颜色种类
  removeEdge: true
}
```
**理由**：超大图处理时间长，使用粗网格和大合并可以显著减少处理时间，同时避免颜色种类过多。

#### 大图（100-400万像素，如 1500×1000）
```javascript
{
  processMode: 'mosaic',
  gridSize: 20,
  mergeThreshold: 80,
  removeEdge: true
}
```
**理由**：平衡处理效果和性能，马赛克模式适合这类图片。

#### 中图（30-100万像素，如 800×600）
```javascript
{
  processMode: 'cartoon',
  gridSize: 12,
  mergeThreshold: 50,
  removeEdge: true
}
```
**理由**：中等尺寸图片使用标准参数，卡通模式可以保留更多细节。

#### 小图（10-30万像素，如 400×300）
```javascript
{
  processMode: 'cartoon',
  gridSize: 8,
  mergeThreshold: 30,
  removeEdge: true
}
```
**理由**：小图使用细网格可以保留更多细节，效果更佳。

#### 超小图（<10万像素，如 200×150）
```javascript
{
  processMode: 'cartoon',
  gridSize: 6,
  mergeThreshold: 20,
  removeEdge: true
}
```
**理由**：超小图使用最细的网格，获得最佳效果。

## 性能优化建议

### 1. 使用智能参数推荐

对于不确定的场景，先调用 `suggestProcessingParams`：

```javascript
// 推荐流程
const suggestion = await suggestProcessingParams({ imageUrl });
const result = await generateBeadMosaic({
  imageUrl,
  ...suggestion.data.suggestedParams
});
```

**优势**：
- 自动根据图片特征选择最佳参数
- 避免参数设置不当导致的性能问题
- 提供参数解释，便于理解

### 2. 利用图片缓存

系统会自动缓存已处理的图片像素数据：

```javascript
// 第1次调用：处理图片（2-5秒）
const result1 = await generateBeadMosaic({
  imageUrl: '/tmp/image.jpg',
  gridSize: 10
});

// 第2次调用：从缓存读取（<100ms）
const result2 = await generateBeadMosaic({
  imageUrl: '/tmp/image.jpg',  // 相同图片
  gridSize: 15  // 不同参数
});
```

**优势**：
- 相同图片重复处理更快
- 适合用户调整参数重新生成的场景

### 3. 进度反馈

对于长耗时操作，使用进度回调：

```javascript
const result = await generateBeadMosaic({
  imageUrl,
  onProgress: ({ stage, percent, message }) => {
    // 向用户展示进度
    updateUI({
      progress: percent,
      message: message
    });
  }
});
```

**进度阶段**：
- `start` (0%)：开始处理
- `loading` (10%)：加载图片
- `processing` (30%)：处理图片
- `calculating` (70%)：计算统计
- `complete` (100%)：处理完成

### 4. 合理管理图纸数据

图纸数据会在内存中存储 1 小时，建议：

```javascript
// 生成图纸后保存 mosaicId
const { mosaicId } = result.data;
saveToLocalStorage({ mosaicId, imageUrl });

// 需要时查询
const stats = await getColorStats({ mosaicId });

// 不再需要时主动删除
await deleteMosaic({ mosaicId });
```

```javascript
  const list = await getPurchaseList({ mosaicId });
  showPurchaseList(list.data);

```

### 2. 参数调整建议

根据用户反馈智能调整参数：

```javascript
// 用户说"格子太大"
if (userSays('格子太大')) {
  // 减小 gridSize
  const newResult = await generateBeadMosaic({
    imageUrl,
    gridSize: Math.max(5, currentGridSize - 3)
  });

  // 增大 mergeThreshold

    imageUrl,

```

### 3. 错误处理与恢复

```javascript
const result = await generateBeadMosaic({ imageUrl });

if (!result.success) {
  switch (result.errorCode) {
    case 1003:  // 图片加载失败
      return {
        message: '图片加载失败了，试试换一张图片吧',
        action: 'chooseAnother'
      };
    
    case 3004:  // 图纸尺寸过大
      return {
        message: '图纸太大了，我帮你调大一点格子尺寸',
        action: 'retryWithLargerGrid',
        newParams: { gridSize: 20 }
      };
    
    case 5003:  // 图纸过期
      return {
        message: '图纸放太久过期了，重新生成一个吧',
        action: 'regenerate'
      };
    
    default:
      return {
        message: result.message,
        action: 'retry'
      };
  }
}
```

## 常见问题解答

### Q1: 为什么处理时间这么长？
**A**: 可能原因：
1. 图片尺寸过大（>100万像素）
2. gridSize 设置过小（<10）
3. mergeThreshold 设置过小（<30）

**解决方案**：
- 使用 `suggestProcessingParams` 获取推荐参数
- 对于大图，使用 gridSize ≥ 20
- 使用马赛克模式（processMode: 'mosaic'）

### Q2: 颜色种类太多怎么办？
**A**: 增大 mergeThreshold 参数：
```javascript
{
  mergeThreshold: 100  // 从默认 50 增大到 100
}
```

### Q3: 导出的 PNG 图片太大怎么办？
**A**: 减小图纸尺寸：
1. 增大 gridSize（如从 10 改为 20）
2. 裁剪原始图片
3. 导出时不包含统计信息（includeStats: false）

### Q4: 如何保留图片细节？
**A**: 使用细网格和小合并阈值：
```javascript
{
  gridSize: 6,           // 细网格
  mergeThreshold: 20,    // 小合并
  processMode: 'cartoon' // 卡通模式
}
```

### Q5: 镜像模式什么时候用？
**A**: 拼豆制作时需要熨烫，图纸需要镜像翻转。如果用户说"我要熨烫"或"看背面效果"，使用：
```javascript
{
  mirrorImage: true
}
```

```javascript
async function fullWorkflow(imageUrl) {
```

### 2. 参数微调

```javascript
// 基于当前参数微调
function adjustParams(currentParams, adjustment) {
  return {
    ...currentParams,
    gridSize: Math.max(5, Math.min(50, currentParams.gridSize + adjustment.gridSize)),
    mergeThreshold: Math.max(0, Math.min(291, currentParams.mergeThreshold + adjustment.mergeThreshold))
  };
}

// 使用
const newParams = adjustParams(currentParams, {
  gridSize: -2,        // 减小 2
  mergeThreshold: 20   // 增大 20
});
```

### 3. 图纸数据缓存

```javascript
// 本地缓存图纸基本信息
const cache = new Map();

function cacheMosaicInfo(mosaicId, info) {
  cache.set(mosaicId, {
    ...info,
    cachedAt: Date.now()
  });
}

function getCachedMosaicInfo(mosaicId) {
  const info = cache.get(mosaicId);
  if (!info) return null;
  
  // 检查是否过期（1小时）
  if (Date.now() - info.cachedAt > 3600000) {
    cache.delete(mosaicId);
    return null;
  }
  
  return info;
}
```
