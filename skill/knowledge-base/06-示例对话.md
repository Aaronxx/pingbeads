## 场景 1：首次生成图纸

### 用户对话
**用户**：帮我把这张图转成拼豆图纸

**AI**：好的，我来帮你生成拼豆图纸。让我先看看这张图片...

### AI 处理流程

```javascript
// 1. 获取参数建议
const suggestion = await suggestProcessingParams({ 
  imageUrl: userImage.imageUrl 
});

// 2. 使用推荐参数生成图纸
const mosaic = await generateBeadMosaic({
  imageUrl: userImage.imageUrl,
  ...suggestion.data.suggestedParams,
  onProgress: ({ percent, message }) => {
    // 向用户展示进度
    showProgress(percent, message);
  }
});

// 3. 展示结果
if (mosaic.success) {
  showResult({
    image: mosaic.data.mosaicId,
    cols: mosaic.data.cols,
    rows: mosaic.data.rows,
    colorCount: mosaic.data.colorCount,
    explanation: suggestion.data.explanation
  });
}
```

### 展示给用户
**AI**：图纸生成完成！
- 图纸尺寸：50×40 格
- 使用颜色：25 种
- 总格子数：2000 个

根据你的图片，我使用了马赛克模式，网格大小 20px，合并阈值 80。这样可以获得较好的效果，同时控制颜色种类。

## 场景 7：错误处理

### 用户对话
**用户**：帮我生成拼豆图纸（上传了一张损坏的图片）

**AI**：好的，让我处理这张图片...

### AI 处理流程

```javascript
const mosaic = await generateBeadMosaic({
  imageUrl: userImage.imageUrl
});

if (!mosaic.success) {
  switch (mosaic.errorCode) {
    case 1003:  // 图片加载失败
      handleError({
        code: 1003,
        message: '图片加载失败了',
        suggestion: '请重新选择一张图片，或使用其他图片'
      });
      break;
    
    case 1001:  // 图片不存在
      handleError({
        code: 1001,
        message: '找不到这张图片',
        suggestion: '请重新选择图片'
      });
      break;
    
    default:
      handleError({
        code: mosaic.errorCode,
        message: mosaic.message
      });
  }
}
```

### 展示给用户
**AI**：抱歉，图片加载失败了。

可能的原因：
1. 图片文件损坏
2. 图片格式不支持

建议：
- 重新选择一张图片
- 使用 JPG、PNG 或 WEBP 格式的图片

需要我帮你重新选择图片吗？

## 对话技巧总结

### 1. 渐进式展示
不要一次性展示所有信息，根据用户需求逐步展示：
- 先生成图纸，展示基本信息
- 用户询问颜色时，展示统计
- 用户需要清单时，导出 CSV
- 用户需要图片时，导出 PNG

### 2. 主动建议
根据用户反馈主动建议：
- "格子太大" → 建议减小 gridSize
- "颜色太多" → 建议增大 mergeThreshold
- "颜色太暗" → 建议增加 vibrantScale

### 3. 错误处理
遇到错误时：
- 解释错误原因
- 提供解决方案
- 引导用户下一步操作

### 4. 参数解释
使用用户友好的语言解释参数：
- gridSize → "格子大小"
- mergeThreshold → "颜色合并程度"
- vibrantScale → "颜色鲜艳度"

### 5. 进度反馈
对于耗时操作，展示进度：
- "正在加载图片..."
- "正在处理图片..."
- "正在计算颜色统计..."
- "图纸生成完成！"
