# 拼豆图纸生成器 - 错误处理指南

## 错误响应格式

所有接口在发生错误时返回统一格式：

```json
{
  "success": false,
  "errorCode": 1001,
  "message": "图片不存在，请检查图片路径或重新选择",
  "details": { /* 可选的错误详情 */ }
}
```

## 错误码分类

| 错误码范围 | 分类 | 说明 |
|-----------|------|------|
| 1001-1999 | 图片相关 | 图片不存在、过大、加载失败等 |
| 2001-2999 | 参数相关 | 参数无效、缺少必要参数等 |
| 3001-3999 | Canvas 相关 | Canvas 不可用、初始化失败等 |
| 4001-4999 | 算法相关 | 算法执行错误、返回空数据等 |
| 5001-5999 | 存储相关 | 存储错误、数据不存在等 |
| 6001-6999 | 环境相关 | wx API 不可用等 |

## 详细错误码列表

### 图片相关错误 (1xxx)

| 错误码 | 错误消息 | 原因 | 解决方法 |
|--------|---------|------|----------|
| 1001 | 图片不存在，请检查图片路径或重新选择 | 图片路径无效或文件不存在 | 检查图片路径是否正确，或重新选择图片 |
| 1002 | 图片尺寸过大，已自动缩放至 4086×4086 以内 | 图片尺寸超出限制 | 系统已自动缩放，无需用户操作 |
| 1003 | 图片加载失败，请尝试重新选择或使用其他图片 | 图片格式不支持或文件损坏 | 尝试使用 JPG、PNG 或 WEBP 格式的图片 |
| 1004 | 图片格式不支持，请使用 JPG、PNG 或 WEBP 格式 | 图片格式不在支持范围内 | 转换图片格式后重试 |

### 参数相关错误 (2xxx)

| 错误码 | 错误消息 | 原因 | 解决方法 |
|--------|---------|------|----------|
| 2001 | 参数无效，请检查输入参数 | 参数值不在允许范围内 | 检查参数范围：gridSize(5-50)、mergeThreshold(0-291)等 |
| 2002 | 缺少必要参数 | 未提供必需参数 | 检查接口文档，确保提供所有必需参数 |
| 2003 | 参数超出范围 | 参数值超出允许范围 | 调整参数到允许范围内 |

### Canvas 相关错误 (3xxx)

| 错误码 | 错误消息 | 原因 | 解决方法 |
|--------|---------|------|----------|
| 3001 | 当前环境不支持图片处理，请升级微信版本 | wx.createOffscreenCanvas 不可用 | 升级微信到最新版本 |
| 3002 | Canvas 初始化失败，请稍后重试 | Canvas 节点获取失败 | 重试或检查页面是否包含必要的 canvas 元素 |
| 3003 | 导出图片失败，请检查存储空间 | canvasToTempFilePath 失败 | 检查设备存储空间 |
| 3004 | 图纸尺寸过大，超出导出限制（4096px） | 导出的 PNG 尺寸超出限制 | 减小 gridSize 参数，或裁剪图纸 |

### 算法相关错误 (4xxx)

| 错误码 | 错误消息 | 原因 | 解决方法 |
|--------|---------|------|----------|
| 4001 | 图纸生成失败，请尝试调整参数或更换图片 | 算法执行异常 | 尝试调整参数或使用其他图片 |
| 4002 | 图纸生成失败：算法返回空数据 | 算法未能生成有效数据 | 检查图片是否有效，或调整参数 |
| 4003 | 颜色映射失败，请检查色号数据 | 颜色映射过程出错 | 检查色号数据是否正确 |

### 存储相关错误 (5xxx)

| 错误码 | 错误消息 | 原因 | 解决方法 |
|--------|---------|------|----------|
| 5001 | 存储错误，请稍后重试 | 数据存储过程出错 | 稍后重试 |
| 5002 | 图纸不存在或已删除，请重新生成 | mosaicId 无效或图纸已被删除 | 重新生成图纸 |
| 5003 | 图纸数据已过期（超过1小时），请重新生成 | 图纸数据已过期被清理 | 重新生成图纸 |

### 环境相关错误 (6xxx)

| 错误码 | 错误消息 | 原因 | 解决方法 |
|--------|---------|------|----------|
| 6001 | wx API 不可用，请确保在小程序环境中运行 | 运行环境不正确 | 确保在微信小程序环境中运行 |
| 6002 | 运行环境错误，请检查小程序配置 | 小程序配置问题 | 检查小程序配置 |

## 错误处理策略

### 1. 自动重试

对于临时性错误（如网络问题、Canvas 初始化失败），可以自动重试：

```javascript
async function withRetry(fn, maxRetries = 3) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await fn();
    } catch (error) {
      // 检查是否为可重试的错误
      if (error.errorCode === 3002 || error.errorCode === 6001) {
        if (i === maxRetries - 1) throw error;
        await new Promise(resolve => setTimeout(resolve, 1000 * (i + 1)));
        continue;
      }
      throw error;
    }
  }
}
```

### 2. 降级方案

当某些功能不可用时，提供降级方案：

```javascript
// Canvas 不可用时，提示用户使用小程序原生功能
if (result.errorCode === 3001) {
  return {
    message: '当前环境不支持图片导出，请使用小程序内的导出功能',
    suggestion: '打开小程序，选择图纸，点击导出按钮'
  };
}
```

### 3. 用户友好提示

将技术性错误转换为用户可理解的提示：

```javascript
const userFriendlyMessages = {
  1001: '找不到这张图片呢，请重新选择一张',
  1003: '图片加载失败了，试试换一张图片吧',
  3004: '图纸太大了，导出会很慢，建议调小格子尺寸',
  5003: '图纸放太久过期了，重新生成一个吧'
};

function getUserFriendlyMessage(errorCode) {
  return userFriendlyMessages[errorCode] || '遇到了一些问题，请稍后重试';
}
```

### 4. 错误日志记录

记录错误详情以便排查：

```javascript
function logError(context, error) {
  console.error(`[${context}] 错误:`, {
    errorCode: error.errorCode,
    message: error.message,
    details: error.details,
    timestamp: new Date().toISOString()
  });
}
```

## 常见错误场景及处理

### 场景 1：用户上传图片后立即处理

**问题**：图片可能还未完全上传完成
**处理**：
```javascript
// 等待图片上传完成
await waitForImageUpload(imageUrl);
// 然后再调用处理接口
const result = await generateBeadMosaic({ imageUrl });
```

### 场景 2：图纸过期

**问题**：用户离开一段时间后返回，图纸数据已过期
**处理**：
```javascript
const result = await getColorStats({ mosaicId });
if (result.errorCode === 5003) {
  // 提示用户重新生成
  return {
    message: '图纸已过期，需要重新生成',
    action: 'regenerate'
  };
}
```

### 场景 3：图片尺寸过大

**问题**：用户上传的图片尺寸过大，处理时间长
**处理**：
```javascript
// 先获取参数建议
const suggestion = await suggestProcessingParams({ imageUrl });
// 使用推荐的参数（会自动调整 gridSize）
const result = await generateBeadMosaic({
  imageUrl,
  ...suggestion.data.suggestedParams
});
```

### 场景 4：导出的 PNG 尺寸超限

**问题**：图纸尺寸过大，超出 4096px 限制
**处理**：
```javascript
const result = await exportMosaicPNG({ mosaicId });
if (result.errorCode === 3004) {
  // 建议用户调整参数
  return {
    message: '图纸尺寸过大，建议减小 gridSize 参数',
    suggestion: '将 gridSize 从 10 调整为 20 或更大'
  };
}
```

## 调试建议

### 1. 查看完整错误信息

```javascript
try {
  const result = await generateBeadMosaic({ imageUrl });
  if (!result.success) {
    console.error('完整错误信息:', result);
  }
} catch (error) {
  console.error('异常:', error);
}
```

### 2. 验证参数

```javascript
function validateParams(params) {
  const errors = [];
  
  if (!params.imageUrl) {
    errors.push('缺少 imageUrl');
  }
  
  if (params.gridSize && (params.gridSize < 5 || params.gridSize > 50)) {
    errors.push('gridSize 必须在 5-50 之间');
  }
  
  return errors;
}
```

### 3. 测试不同图片

使用不同尺寸、格式的图片测试，确保兼容性：
- 小图（<10万像素）
- 中图（30-100万像素）
- 大图（>100万像素）
- 不同格式：JPG、PNG、WEBP
