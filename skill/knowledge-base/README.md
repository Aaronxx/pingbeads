## 使用指南

### 对于微信AI

当用户提问时，AI可以根据问题类型检索相关文档：

1. **基础问题**（什么是拼豆图纸？怎么用？）
   → 参考 `01-快速入门.md`

2. **技术问题**（接口怎么调用？参数是什么？）
   → 参考 `02-接口文档.md`

3. **错误处理**（报错了怎么办？错误码是什么？）
   → 参考 `03-错误处理.md`

4. **效果优化**（如何让图纸更精细？如何减少颜色？）
   → 参考 `04-最佳实践.md`

5. **常见问题**（处理时间长？图纸过期？）
   → 参考 `05-常见问题.md`

6. **对话场景**（用户说"帮我生成图纸"怎么处理？）
   → 参考 `06-示例对话.md`

### 对于开发者

开发者可以按照以下顺序阅读文档：
1. 先阅读 `01-快速入门.md` 了解产品
2. 再阅读 `02-接口文档.md` 了解接口
3. 然后阅读 `04-最佳实践.md` 学习使用技巧
4. 遇到问题时查阅 `03-错误处理.md` 和 `05-常见问题.md`
5. 参考 `06-示例对话.md` 了解交互方式
