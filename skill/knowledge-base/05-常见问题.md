# 拼豆图纸生成器 - 常见问题 FAQ

## 基础问题

### Q1: 这个工具是做什么的？
**A**: 拼豆图纸生成器将用户提供的图片转换为 MARD 品牌拼豆色彩的马赛克图纸。用户可以根据图纸购买对应颜色的拼豆，进行手工制作。

### Q2: 支持哪些图片格式？
**A**: 支持 JPG、PNG、WEBP 格式的图片。建议使用清晰的图片以获得更好的效果。

### Q3: 图片尺寸有限制吗？
**A**: 图片尺寸限制为 4086×4086 像素。超过这个尺寸的图片会自动缩放处理。

### Q4: 处理一张图片需要多长时间？
**A**: 通常 2-5 秒，具体取决于：
- 图片尺寸（像素数量）
- 参数设置（gridSize 越小处理越慢）
- 设备性能

### Q5: 生成的图纸数据会保存多久？
**A**: 图纸数据在会话期间有效，最长保存 1 小时。超过 1 小时后需要重新生成。

## 参数相关问题

### Q6: gridSize 是什么意思？
**A**: gridSize 控制格子的大小（像素）。数值越小，格子越多越精细；数值越大，格子越少越粗糙。

**参考值**：
- 5-8：非常精细（适合小图）
- 10：中等（默认）
- 15-20：较粗糙（适合大图）
- 30-50：非常粗糙

### Q7: mergeThreshold 是什么意思？
**A**: mergeThreshold 控制颜色合并程度。数值越大，相似颜色合并越多，最终颜色种类越少。

**参考值**：
- 0：不合并（保留所有细节）
- 50：中等合并（默认）
- 100：较大合并
- 291：最大合并（颜色种类最少）

### Q8: 什么时候使用马赛克模式？
**A**: 马赛克模式（mosaic）适合照片类图片，会智能合并相似色块。卡通模式（cartoon）适合插画、卡通图，保留更多细节。

**简单判断**：
- 照片 → 马赛克模式
- 插画/卡通 → 卡通模式

### Q9: vibrantScale 怎么使用？
**A**: vibrantScale 调整颜色鲜艳程度：
- -10：最柔和（复古风格）
- 0：原色（默认）
- 10：最鲜艳（高饱和度）

**使用场景**：
- 想要复古效果 → vibrantScale: -5
- 想要鲜艳效果 → vibrantScale: 5

### Q10: mirrorImage 什么时候用？
**A**: 拼豆制作时需要熨烫，图纸需要镜像翻转才能正确拼制。如果用户要制作实物，建议使用镜像模式。

## 使用流程问题

### Q11: 如何开始使用？
**A**: 标准流程：
1. 用户上传图片
2. 调用 `suggestProcessingParams` 获取推荐参数
3. 调用 `generateBeadMosaic` 生成图纸
4. 展示图纸预览和颜色统计
5. 用户可选择导出采购清单或图纸图片

### Q12: 如何调整参数重新生成？
**A**: 保存首次生成的 mosaicId，然后使用新参数重新调用 `generateBeadMosaic`：

```javascript
// 首次生成
const result1 = await generateBeadMosaic({
  imageUrl: '/tmp/image.jpg',
  gridSize: 10
});

// 调整参数重新生成
const result2 = await generateBeadMosaic({
  imageUrl: '/tmp/image.jpg',
  gridSize: 15  // 使用新参数
});
```

### Q13: 如何获取采购清单？
**A**: 使用 `getPurchaseList` 接口：

```javascript
const list = await getPurchaseList({
  mosaicId: 'mosaic_xxx',
  format: 'csv'  // 或 'text'
});

// list.data.content 包含 CSV 内容
```

### Q14: 如何导出图纸图片？
**A**: 使用 `exportMosaicPNG` 接口：

```javascript
const png = await exportMosaicPNG({
  mosaicId: 'mosaic_xxx',
  includeStats: true,  // 包含颜色统计
  showCode: true       // 显示色号
});

// png.data.tempFilePath 是图片临时路径
```

### Q15: 如何查看图纸的详细信息？
**A**: 使用 `getMosaicDetail` 接口：

```javascript
const detail = await getMosaicDetail({
  mosaicId: 'mosaic_xxx',
  includeGridData: false  // 是否包含网格数据
});
```

## 错误处理问题

### Q16: 提示"图片加载失败"怎么办？
**A**: 可能原因：
1. 图片路径无效
2. 图片格式不支持
3. 图片文件损坏

**解决方法**：
- 检查图片路径是否正确
- 转换为 JPG、PNG 或 WEBP 格式
- 重新选择图片

### Q17: 提示"图纸尺寸过大"怎么办？
**A**: 导出的 PNG 尺寸超出 4096px 限制。

**解决方法**：
- 减小 gridSize 参数（如从 10 改为 20）
- 裁剪原始图片
- 导出时不包含统计信息

### Q18: 提示"图纸数据已过期"怎么办？
**A**: 图纸数据超过 1 小时已被清理。

**解决方法**：
- 重新生成图纸
- 建议用户及时使用生成的图纸

### Q19: 提示"Canvas 不可用"怎么办？
**A**: 当前环境不支持 Canvas API。

**解决方法**：
- 升级微信到最新版本
- 使用小程序内的原生导出功能

### Q20: 处理时间太长怎么办？
**A**: 可能原因：
1. 图片尺寸过大
2. gridSize 设置过小
3. 设备性能不足

**解决方法**：
- 使用 `suggestProcessingParams` 获取推荐参数
- 对于大图，使用 gridSize ≥ 20
- 使用马赛克模式（processMode: 'mosaic'）

## 效果优化问题

### Q21: 如何让图纸更精细？
**A**: 减小 gridSize 和 mergeThreshold：

```javascript
{
  gridSize: 6,           // 细网格
  mergeThreshold: 20     // 小合并
}
```

**注意**：这会显著增加处理时间和颜色种类。

### Q22: 如何减少颜色种类？
**A**: 增大 mergeThreshold：

```javascript
{
  mergeThreshold: 100    // 从 50 增大到 100
}
```

### Q23: 如何处理有白边的图片？
**A**: 使用 removeEdge 参数：

```javascript
{
  removeEdge: true       // 去除边缘底色
}
```

### Q24: 如何保留图片的细节？
**A**: 使用细网格和小合并阈值，并选择卡通模式：

```javascript
{
  processMode: 'cartoon',
  gridSize: 6,
  mergeThreshold: 20
}
```

### Q25: 如何让颜色更鲜艳？
**A**: 使用正的 vibrantScale：

```javascript
{
  vibrantScale: 5        // 正值表示鲜艳
}
```

## 高级问题

### Q26: 可以自定义色卡吗？
**A**: 当前版本暂不支持自定义色卡，固定使用 MARD 291 色。

### Q27: 可以批量处理多张图片吗？
**A**: 可以，但建议串行处理以避免内存溢出：

```javascript
for (const imageUrl of imageList) {
  const mosaic = await generateBeadMosaic({ imageUrl });
  // 处理结果
}
```

### Q28: 图纸数据可以持久化保存吗？
**A**: 当前版本图纸数据存储在内存中，会话结束后清空。如需持久化，需要自行实现存储逻辑。

### Q29: 如何处理透明背景的图片？
**A**: 透明背景会被视为白色。建议先处理图片，去除透明背景。

### Q30: 可以只处理图片的某一部分吗？
**A**: 当前版本不支持区域选择。建议先裁剪图片，再上传处理。

## 性能问题

### Q31: 相同图片重复处理会更快吗？
**A**: 是的，系统会自动缓存图片像素数据。相同图片重复处理时，直接从缓存读取，速度更快。

### Q32: 如何优化处理性能？
**A**: 
1. 使用 `suggestProcessingParams` 获取推荐参数
2. 对于大图，使用较大的 gridSize（≥20）
3. 使用马赛克模式处理照片
4. 利用图片缓存机制

### Q33: 内存占用会很大吗？
**A**: 主要内存占用来自：
- 图片像素数据（自动缓存，最多10张）
- 图纸网格数据（每张图纸）

建议定期删除不需要的图纸数据：

```javascript
await deleteMosaic({ mosaicId });
```

### Q34: 可以同时处理多少张图片？
**A**: 建议串行处理，避免内存溢出。如果必须并行处理，建议不超过 3 张。

### Q35: 导出的 PNG 图片质量如何？
**A**: 导出的 PNG 使用 Canvas 渲染，质量取决于：
- 图纸尺寸（cols × rows × cellSize）
- 是否显示色号
- 是否包含统计信息

默认 cellSize 为 20px，质量较好。

## 其他问题

### Q36: MARD 色号是什么意思？
**A**: MARD 是德国拼豆品牌，有 291 种标准颜色。色号格式为字母+数字，如 A01、B12、C23。

### Q37: 特殊色是什么？
**A**: 特殊色包括 P/Q/R/T/ZG 系列，这些颜色较难购买。默认不使用特殊色，如需使用，设置：

```javascript
{
  useSpecialColors: true
}
```

### Q38: 如何知道需要购买哪些颜色？
**A**: 使用 `getPurchaseList` 导出采购清单：

```javascript
const list = await getPurchaseList({
  mosaicId: 'mosaic_xxx',
  format: 'csv'
});
```

CSV 包含色号、颜色、数量，可直接用于采购。

### Q39: 可以预览图纸效果吗？
**A**: 可以，使用 `exportMosaicPNG` 导出预览图：

```javascript
const png = await exportMosaicPNG({
  mosaicId: 'mosaic_xxx',
  includeStats: false,  // 不显示统计
  showCode: true        // 显示色号
});
```
