# Mark 色彩马赛克 - 微信小程序技术文档

## 一、项目目标

### 1.1 核心功能
将用户选择的普通图片转换为 Mark（MARD）品牌拼豆/米珠色彩的马赛克图案，并提供以下功能：

1. **图片转马赛克** - 将图片转换为 Mark 品牌颜色的像素画
2. **色块统计** - 统计每种颜色需要的豆子数量
3. **高亮交互** - 点击颜色统计列表，高亮对应色块，灰色显示其他颜色
4. **色号标注** - 可选择在每个色块上显示 Mark 色号
5. **手指缩放** - 支持双指缩放查看细节
6. **导出功能** - 支持导出 PNG 图片、CSV 采购清单

### 1.2 Mark 品牌色号
Mark（原 MARD）是德国知名拼豆品牌，拥有 291 种标准颜色。本项目实现了将任意图片颜色映射到最接近的 Mark 色号。

```
│  └── statsCalculator.js - 统计计算                      │
├─────────────────────────────────────────────────────────┤

└─────────────────────────────────────────────────────────┘
```

### 3.2 核心算法

#### 3.2.1 颜色映射算法 (colorMapper.js)

**欧氏距离计算**:
```
distance = √((r1-r2)² + (g1-g2)² + (b1-b2)²)
```

**最近颜色查找**:
1. 遍历 Mark 色号调色板（291 种颜色）
2. 计算输入颜色与每个 Mark 颜色的欧氏距离
3. 返回距离最小的 Mark 色号

**核心函数**:
```javascript
findClosestMarkColor(rgb) // 返回 { code, hex, rgb }
```

#### 3.2.2 图像处理算法 (imageProcessor.js)

**主导色提取**:
- 将图片分割为网格（gridSize 可配置）
- 计算每个网格内所有像素的 RGB 平均值
- 使用平均值作为该网格的主导色

**马赛克生成**:
```
1. 根据 gridSize 计算网格数量 (cols × rows)
2. 对每个网格提取主导色
3. 将主导色映射到最近的 Mark 色号
4. 返回网格数据结构
```

**区域合并** (可选):
- 使用 BFS 算法合并相邻的相似颜色
- 相似度阈值可配置 (mergeThreshold)

#### 3.2.3 统计计算 (statsCalculator.js)

- 遍历网格数据，统计每种 Mark 色号的出现次数
- 按数量降序排序
- 生成 CSV 采购清单

### 3.3 组件设计

#### 3.3.1 imagePicker 组件
- 使用 `wx.chooseMedia` 选择图片
- 支持相册和相机
- 触发 `imageSelected` 事件

#### 3.3.2 mosaicCanvas 组件
- 使用 Canvas 2D 渲染马赛克
- 支持 `highlightCode` 属性实现高亮
- 支持 `showCode` 属性显示色号标注
- 支持 `scale` 属性实现缩放
- 支持双指触摸缩放

**渲染流程**:
```
1. 加载图片到 Canvas
2. 获取像素数据
3. 生成拼豆图纸网格数据
4. 遍历网格绘制色块
5. 可选：绘制色号标注
```

#### 3.3.3 colorStats 组件
- 接收 mosaicData 属性
- 计算颜色统计
- 支持排序切换（按数量/按色号）
- 点击色块触发高亮事件

### 3.4 页面交互流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  选择图片   │────>│ 生成拼豆图纸  │────>│ 显示统计   │
└─────────────┘     └─────────────┘     └─────────────┘
       │                   │                   │
       v                   v                   v
  imagePicker         mosaicCanvas         colorStats
  触发事件           渲染画布            展示统计
```

### 3.5 关键技术点

1. **离屏 Canvas**: 使用 `wx.createOffscreenCanvas` 获取图片像素数据
2. **颜色空间**: RGB 颜色空间，使用欧氏距离
3. **性能优化**: 网格化处理，减少计算量
4. **交互实现**: 观察者模式实现数据响应

## 四、数据结构

### 4.1 Mark 色号对象
```javascript
{
  code: 'A01',      // 色号
  hex: '#FAF4C8',   // 十六进制颜色
  rgb: { r: 250, g: 244, b: 200 } // RGB 对象
}
```

### 4.2 网格单元格对象
```javascript
{
  x: 0,           // X 坐标
  y: 0,           // Y 坐标
  width: 10,      // 宽度
  height: 10,     // 高度
  originalRgb: { r: 100, g: 100, b: 100 }, // 原始颜色
  markCode: 'A01', // 对应的 Mark 色号
  markHex: '#FAF4C8', // Mark 颜色
  merged: false    // 是否已合并
}
```

### 4.3 统计结果对象
```javascript
{
  colorCount: 10,        // 颜色种类数
  totalCount: 500,      // 总色块数
  sortedByCount: [...],  // 按数量排序
  sortedByCode: [...],   // 按色号排序
  purchaseList: '...',   // CSV 格式
  simpleList: [...]      // 简化清单
}
```

## 五、配置参数

| 参数 | 说明 | 默认值 | 范围 |
|------|------|--------|------|
| gridSize | 网格大小（像素） | 10 | 2-50 |
| mergeThreshold | 颜色合并阈值 | 30 | 0-150 |
| showCode | 是否显示色号标注 | false | - |
| scale | 缩放比例 | 1 | 0.5-3 |
